## What's new in 0.4.0

### Board

- Right-click empty board space to create a chat, note, code or file node at the pointer.
- A new node from the toolbar or the board menu takes the nearest free spot around the point it was created at.
- The × button of a wire sits on a visible part of the wire, outside every node. Rest the pointer on a wire to get a second × at that point, or right-click the wire and choose **Delete Connection**.
- Wires curve more gently, and the connection dots sit just outside the node border.

### Top bar

- **Settings → Top bar → Active jobs style:** Mini is a compact version of the Active jobs list with one line per job (status dot, title and run time). Hover a row to see its status and board and to stop the run.
- **Settings → Top bar → OpenCode cost periods:** the OpenCode cost meter shows the cost of the last hour, day, week or 30 days, in any combination. The figure includes runs that are still going.
- Small visual improvements.

### Runtimes

- **Claude:** added support for Claude skills and commands autofill in the `/` menu.
- **OpenCode:** added support for Effort.
- With subagents shown inside the parent node (Settings → Nodes), approvals and questions from a subagent now appear in the parent node.
- The children of a stopped node now receive its answer as text and start a new session.

## Update

```bash
npx branchboard@latest
```
